# dkit-blue resource licences

The `dkit-blue` layout, CSS, LaTeX files, matplotlib files, and cover are
reference resources for dkit and are distributed under the repository MIT
licence.

The DOCX template is a generated, unbranded Office Open XML template and is
also distributed under the repository MIT licence. It contains no embedded
third-party fonts or images.

The bundled Source Sans Pro font files are distributed under the SIL Open Font
License, Version 1.1. The complete licence text is in `OFL-1.1.txt`.
